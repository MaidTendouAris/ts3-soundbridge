# TS3 SoundBridge 1.0.0

首个正式发布的 Windows x64 安装包，适用于 TeamSpeak 3 插件 API 26 和 Windows build 20348+。

- 原生中文 GUI，调节来源、应用多选、两路音量、麦克风独立静音和共享开关，保存设置。
- 共享全部非当前 TS3 进程树的声音，或同时共享多个指定应用；应用重启自动重新关联，重叠父子树去重。
- 默认每天检查一次正式 GitHub Releases；可关闭自动检查，并通过设置窗口或插件菜单手动检查。
- SVG 作为图标基准，生成窗口 ICO 和菜单 PNG；源码和图标采用 MIT 协议。

下载 `TS3-SoundBridge-1.0.0-win64.ts3_plugin`，完全退出 TS3 后运行安装包，再重启启用插件。`SHA256SUMS.txt` 用于核对下载文件。更新检查提供官方发布页入口，安装由用户完成。

已通过本机构建、四组自动测试、GUI 操作、真实 Windows 进程排除、多应用捕获和重启恢复测试。GitHub Actions 会在发布前再次构建并测试。

真实 TS3 频道发送效果、PTT／VAD、长期音质及端到端延迟仍需实测；当前优先持续发送与耳机场景。首次捕获后模块保留至进程退出，更新前必须完全关闭 TS3。
