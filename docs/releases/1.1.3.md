# TS3 SoundBridge 1.1.3

- 新增 English／简体中文／繁體中文／한국어／日本語五种语言，设置窗口顶部提供语言选择。
- 选择后即时切换并保存，下次启动保留偏好。首次使用跟随 Windows 显示语言，不支持的语言回退为英文。
- 覆盖设置控件、应用状态、运行详情、采集错误、自动／手动更新信息，以及插件菜单、热键名称和本地通知。已有错误与更新结果也能切换语言，无需重新采集或检查更新。
- 切换语言保留尚未应用的来源及偏好，不中断音频共享；窗口保持原有紧凑双栏尺寸。
- TS3 缓存的菜单和热键名称在重新加载插件后更新，原有热键绑定保持有效。

English: Five interface languages are now available. Select a language at the top of Settings; it takes effect immediately and is remembered. Reload the plugin to refresh TS3 menu and hotkey labels.

下載／다운로드／ダウンロード：`TS3-SoundBridge-1.1.3-win64.ts3_plugin`。完全退出 TS3 后安装。Release 仅附安装包与 `SHA256SUMS.txt`，不单独附图标文件。保留 0–300% 实时增益、按需平滑电平及全部／指定应用共享模式；适用于 Windows build 20348+、TS3 x64、插件 API 26，采用 MIT 协议。
