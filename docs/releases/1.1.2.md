# TS3 SoundBridge 1.1.2

- 两路音量滑块改为拖动即时生效，无需点击“应用设置”；短暂停顿后自动保存，松手或关闭窗口时也会保存。
- 存在未应用的来源、应用选择、独立静音或更新偏好时，顶部显示橙色提示，相应项目和“应用设置”按钮带星号。应用成功或改回原值后清除提示，无待定修改时按钮置灰。
- 实时调音量不会顺带应用其他待定设置；隐藏并重新打开窗口会保留待定修改。
- 电平随增益变化同步调整，清除旧增益的峰值与平滑残留；0% 立即显示静音。

此前电平计算已位于应用增益之后，但滑块百分比会先更新，实际增益必须点击应用才生效，容易造成误判。本版统一滑块显示、实际增益与电平的生效时机。

下载 `TS3-SoundBridge-1.1.2-win64.ts3_plugin`，完全退出 TS3 后安装。Release 仅附安装包与 `SHA256SUMS.txt`，不单独附图标文件。保留紧凑双栏、按需电平及 0–300% 增益范围；适用于 Windows build 20348+、TS3 x64、插件 API 26，采用 MIT 协议。
