# TS3 SoundBridge 1.1.0

- 新增共享声音与麦克风两条实时峰值电平条，分别显示各自应用增益后的音量，使用同一 dBFS 刻度，便于比较。
- 设置窗口改为紧凑双栏，应用列表与音量／电平并排，降低高 DPI 下的窗口高度。
- 电平每 50 ms 刷新，瞬时响应峰值并缓慢回落；接近满幅变黄，满幅／过载变红，并保留正 dBFS 读数。开始共享后显示，停止共享后归零。
- 两路增益范围由 0–200% 扩展为 0–300%；默认仍为共享声音 50%、麦克风 100%，兼容已有配置。
- 使用新绘制的深紫、浅紫与杏橙色声波箭头图标。

下载 `TS3-SoundBridge-1.1.0-win64.ts3_plugin`，完全退出 TS3 后安装，再启动启用插件。调整音量后点击“应用设置”，电平显示当前已应用的增益。`SHA256SUMS.txt` 可核对下载文件。

适用于 Windows build 20348+、TeamSpeak 3 x64、插件 API 26。保留 TS3 原有麦克风发言规则；真实频道听感、PTT／VAD、长期音质及设备自动恢复仍待实测。源码和图标采用 MIT 协议。
