# TS3 SoundBridge 1.1.1

- 新增“显示实时电平”总开关，默认关闭，点击立即生效并记住偏好。关闭显示或隐藏／最小化窗口时，停用电平计算和高频刷新，音频共享继续；停止共享后电平也暂停。
- 电平采用指数平滑、短峰值保持与约 30 帧／秒刷新，缓和上升和回落的跳动；数值降低刷新频率。原始峰值过载仍单独保留红色提示，避免被平滑掩盖。
- 图标圆点移至画布正中心，重新生成实际 PNG／ICO。
- Release 附件只保留 `.ts3_plugin` 安装包与 `SHA256SUMS.txt`，不再单独附带 SVG、PNG 或 ICO。窗口／菜单仍使用插件自带的图标。

下载 `TS3-SoundBridge-1.1.1-win64.ts3_plugin`，完全退出 TS3 后安装。需要比较两路电平时，开始共享后勾选“显示实时电平”；两路 0–300% 增益调整仍须点击“应用设置”。

适用于 Windows build 20348+、TeamSpeak 3 x64、插件 API 26。保留紧凑双栏窗口、指定应用共享与 TS3 原有麦克风发言规则。源码和图标采用 MIT 协议。真实频道听感、PTT／VAD、长期音质和设备自动恢复仍待实测。
